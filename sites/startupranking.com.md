# startupranking.com

- **Submit URL:** https://www.startupranking.com/login (no direct `/register` — 404; "Create Startup" also routes through login).
- **Login:** Google/Facebook/LinkedIn/X only, no email option. On a clean profile Google login works with the same pattern as other sites — snapshot then click by element ref, no popup, same tab.
- **Captcha / bot protection:** none observed.
- **Price:** listing registration is free; an "UPGRADE" option on the card is a paid tier, not used.
- **Form fields:** Startup Name; Legal Name (the registered business entity name); Phrase/Slogan (trimmed to a 60-char one-liner); Country; State (jurisdiction of the legal entity — get this from the owner if it isn't obvious, don't guess); Founded Date (use the earliest verifiable date if no official founding date exists, e.g. first repo commit); Business Type (B2C if sold directly to consumers); Industry (closest match from the fixed list — e.g. Software, Internet & Computer Services); Description (300+ chars needed); Tags (from the site's autocomplete, pick the closest match); Contact email. Social links (Facebook/Twitter/LinkedIn) should point to a company profile, not a personal one — leave blank if only a personal profile exists, filling a personal link would violate the site's own field intent.
- **Logo & limits:** standard file input, uploads via a DataTransfer workaround. Logo is added through a SEPARATE "Edit with approval" form after initial submission — it isn't part of the first-submission form, and it goes to moderation rather than publishing instantly (a placeholder initials badge shows until approved).
- **Country/State/Business Type/Industry are `chosen` widgets over native `<select>` elements** — a plain select-by-label tool call won't work since these render as styled `<span>`s, not real selects. Set the underlying select's `.value` directly and dispatch a `change` event to make it register. If a `chosen` dropdown gets stuck open, a real mouse click on the page body (not a programmatic one) closes it.
- **Email confirmation:** not encountered on this path.
- **Moderation:** the listing publishes immediately on submit with a banner ("registered, review team will review it") — appearing publicly doesn't wait for the "official review". The separate logo edit goes into its own moderation queue with no stated turnaround.
- **Pitfalls:** the browser automation session dropped mid-flow once ("session not registered or already stopped") — had to start a fresh session and redo the logo-upload steps; the core listing had already saved by that point, so nothing else was lost.
- **Last checked:** 2026-09-27 — Listed; live and public with full profile fields filled. Logo submitted separately and pending its own moderation queue.
