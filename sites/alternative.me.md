# alternative.me

- **Submit URL:** https://alternative.me/account/submissions → "Submit Software" (opens a "Software Submission" modal)
- **Login:** email/password, existing account. The session did not persist between visits — required logging in again.
- **Captcha / bot protection:** none encountered
- **Price:** no listing price from the site itself; the product card has an optional "Pricing (if available)" block — one tier was added (a Starter-level monthly price)
- **Link type:** unknown
- **Form fields:** Software Name; Category → native select, closest available value is "Web > Media" (no "video" option); Type → "Online / SaaS"; Monetization → "Paid" (honest per real pricing); Status → "Released" (default, unchanged); Short Description — pitfall: must be ≥100 characters, the standard ~61-char tagline is rejected, use a longer sentence pulled from the canonical long description instead; Full Description → canonical long description plus a pricing note; Homepage URL; Platforms → Browser; Pricing → one tier from the real pricing grid
- **Logo & limits:** two unlabeled file inputs distinguished only by surrounding text ("Click to upload" = icon, "Drop your files here..." = screenshot); after a successful upload that input disappears from the DOM and is replaced by a preview, so the file-input index for the second upload must be re-queried afterward (index 0, not 1)
- **Email confirmation:** not encountered
- **Moderation:** after submit, the card moves from Saved Drafts to Pending Submissions with a "Pending Approval" status — confirmed by reloading the page, not just an optimistic UI update
- **Pitfalls:** the "Next" button on step 1 of the modal is a styled `<span>`, not a real button, and there's no `<form>` element on the page at all, so a form-level submit call can't be used — a normal click on it works (though it may not always; a modal that silently closes without saving on one attempt is a known possible site bug). The category/type/status selects show human-readable labels but their real values are machine slugs — read them by inspecting the select's actual option values, don't guess from the label text. The Platforms select has a distinct site bug: every option's underlying value is identical (a generic placeholder string), so setting the select value directly always lands on the first option (Windows) — the fix is to set the selected index by number and dispatch a change event, then verify by reading the selected option's text. The modal's close button and Escape both discard the visible modal, but the draft is already saved server-side by then.
- **Last checked:** 2026-09-27 — Pending review ("Pending Approval" in the account's Pending Submissions list, with logo, screenshot, category, and one pricing tier)
