# toolkitly.com

- **Submit URL:** https://www.toolkitly.com/submit — a 5-step wizard.
- **Login:** Google OAuth.
- **Captcha / bot protection:** none.
- **Price:** paid only — Starter $29 / Growth $49 / Elite $99 (all one-time fees), no free plan or skip option exists. This only becomes clear at the final step ("Finish" leads to a pricing page, not a confirmation).
- **Link type:** dofollow claimed on paid tiers, with faster indexing on the cheapest ($29) tier.
- **Form fields:** Basic Tool Information (Name/URL/Company/Location as separate inputs), Categories (native multi-select styled as a combobox — select by option index, not by visible label matching), Detailed Description (CKEditor 4 rich-text field — set via the editor's API, not a plain fill), Pricing (native select: Free/Premium/Freemium/Ask For Price, plus name/price text fields), FAQs (question/answer textareas), Images (two file inputs — a 640×313 screenshot and a 128×128 logo; accepts plain PNG without the strict format checks some other sites enforce).
- **Logo & limits:** logo 128×128, screenshot 640×313, both plain PNG.
- **Email confirmation:** unknown.
- **Moderation:** each of the 5 steps needs its own "Submit" click inside the step (an AJAX save shows a confirmation toast) before "Continue" to the next step appears — clicking an inactive step tab does nothing.
- **Pitfalls:** all data entered and saved as a draft on the site's side across all 5 steps, but publishing is blocked behind payment — the flow was stopped at the pricing screen without paying.
- **Last checked:** 2026-09-27 — Needs a human: draft fully filled and saved on the site, paid-only publish requires an owner decision on which tier to buy (Starter $29 is the cheapest path to a dofollow backlink and Google indexing within about a week).
