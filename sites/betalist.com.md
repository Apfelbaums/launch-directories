# betalist.com

- **Submit URL:** https://betalist.com/submissions/new
- **Login:** email/password, self-serve signup available (not X/Twitter-only)
- **Captcha / bot protection:** none on signup or the submission form
- **Price:** the wizard auto-drafts a listing from your domain (text, topics, a site screenshot), but step 3 ("ready to launch") only offers paid packages — roughly $299 / $99 / $39 one-time tiers. There is no free path at all; even continuing the submission requires payment.
- **Link type:** unknown
- **Form fields:** Product name; Pitch → replace the auto-generated text with the standard tagline; Description → canonical short description; Topics → auto-suggested topics were mostly accurate and left as-is; Icon → uploaded logo
- **Logo & limits:** the page has two file inputs sharing the same name attribute — one hidden (a framework placeholder for an empty value) and one a real file input; any upload selector must explicitly target the file-type input or the upload silently fails
- **Email confirmation:** not encountered on the signup → draft → paywall path
- **Moderation:** never reached — blocked by payment before moderation
- **Pitfalls:** a fully-completed draft (correct logo and canonical text) exists and passes step 2, but there's no visible account/submissions page outside the wizard (404s), so it's unclear whether anything persists past the unpaid step-3 wall.
- **Last checked:** 2026-09-27 — Paid only (no free submission tier; left unsubmitted rather than pay)
