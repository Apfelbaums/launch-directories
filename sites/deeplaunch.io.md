# deeplaunch.io

- **Submit URL:** https://deeplaunch.io/submit
- **Login:** initially none; a later visit started requiring login (Google or GitHub OAuth)
- **Captcha / bot protection:** none
- **Price:** a Free Listing exists but requires a dofollow badge (an embed snippet) live in the footer of your own site — a site-content decision, not made unilaterally. Paid tiers exist from roughly $5–$30/mo, plus a lifetime one-time option and a higher annual tier.
- **Link type:** dofollow badge required for the free tier
- **Form fields:** URL, Name, Tagline (61 chars), Description (~1000 chars, canonical long description plus a pricing note), Categories → Video + Content Creators + Social Media, Platforms → Web, Pricing Model → Freemium (this field can reset after a login-triggered form reload — recheck it)
- **Logo & limits:** an earlier attempt to upload a logo via a data-URI/local-file fetch failed with "Not allowed"; a standard fetch → File → DataTransfer upload technique worked instead
- **Email confirmation:** unknown
- **Moderation:** "Pending Review," roughly a 2-day window per the site's own stated policy
- **Pitfalls:** a shared email-input selector can accidentally target the page's footer newsletter-signup field instead of the submission form's own email field — check before submitting, don't subscribe by accident. Logging in mid-flow can reset some already-filled fields (Pricing Model in particular) — recheck the whole form after login.
- **Last checked:** 2026-09-27 — Pending review (once the reciprocal badge was placed on the product's own site and login completed)
