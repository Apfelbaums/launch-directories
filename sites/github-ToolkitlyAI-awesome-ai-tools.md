# github.com/ToolkitlyAI/awesome-ai-tools

- **Submit URL:** pull request against the repo (fork + edit via the GitHub web editor)
- **Login:** GitHub account
- **Captcha / bot protection:** none
- **Price:** free
- **Link type:** dofollow (markdown link)
- **Form fields:** Tool Name, Description (hard cap: 50 characters), Website — a table row appended to a category file
- **Logo & limits:** n/a
- **Email confirmation:** n/a
- **Moderation:** standard PR review. Repo context: 650+ tools listed, actively maintained, the most formalized process seen — has a CONTRIBUTING.md on a non-default branch.
- **Pitfalls:** edits go into a specific category file under a `Category/` folder, not the top-level README (the README is only a table of contents linking to category files) — easy to edit the wrong file. The 50-character description cap is tight and strictly enforced; no promotional language allowed.
